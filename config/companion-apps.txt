# mrk companion apps
#
# The apps of mine that install-apps installs from their GitHub releases:
# make apps, and Phase 3. It installs an app only when the app is signed by
# the Developer ID team that GITHUB_APP_TEAM_ID in scripts/install-apps names,
# and it skips an app that is already in /Applications.
#
# One app on each line:
#   <bundle name>|<repo holding the releases>|<display name>
# A line that starts with # is a comment, and an empty line is ignored. Keep
# the lines in byte order (LC_ALL=C sort).
#
# Kept as data so adding an app is one line. Two things this list encodes
# that are easy to get wrong:
#
#   - ClipHack's DMGs are published to a SEPARATE repo, ClipHack-releases. Its
#     source repo has no release assets at all.
#   - Magic Backup Machine's bundle is "Magic Backup Machine.app" while its DMG
#     is MagicBackupMachine-*.dmg. install_github_app compares bundle names, so
#     the spacing here is load-bearing.
#
# Perfect Passwords Grabber is absent because it is not installed on this Mac.
# WireHack, JustLoop and JustIn are retired: ClipHack supersedes WireHack, and
# WaxOn/WaxOff covers JustIn. Cypher/FL2601 is retired too (2026-09-23), and
# never came from here: being sandboxed with no network entitlement, it could
# not check for its own updates, so it was a Homebrew cask.
